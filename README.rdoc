== README

The system to predict a football match with your friends

* Score system

  Group stage
    +2  : prediction is exactly same as final result of the match
          (ex: the match result is 2-1, and you predicted 2-1)
    +1  : same outcome (winner or draw)
          (ex: the match result is 2-1, and you predicted 3-1 -> the team won, but with different result)

  Knockout stage
    You choose ONE winner (a draw is not allowed). The match can have a handicap
    (bet priority, "prior1"/"prior2"): the handicap is subtracted from the score of
    each team before deciding the winner. For a "special final" the extra time and
    penalty scores are also taken into account.

* Reward

  Group stage   : each exact prediction gets reward_percent x fee x (number of players) / (number of winners)
  Knockout stage: the pot (fee x number of predictions) is shared between the winners.
                  With a quarter handicap, a half win gets half of the pot share + half fee,
                  and a half loss gets half of the fee back.
                  If nobody wins, the pot is saved in the cup (save_reward) and added to the
                  next knockout match; in a league every player gets the fee back.

* Permission

  Only admin could add/update/delete Cup/Team/Match, recalculate results, reset a player's
  password (a random one is generated and shown once) and remove a player from a cup.
  Users could add/update/delete their own Prediction only, until the match starts.

* Closed prediction

  Prediction will be closed when the match starts !
  However, you can set environment variable "SKIP_VALIDATION" to "true" for allowing updating prediction at any time !

* Results and import (football-data.org)

  Teams, matches and results are imported from https://www.football-data.org (v4 API).
  Set "FOOTBALL_API_KEY" and the "result_id" of the cup (the competition id) to enable it.
  Results of started matches are refreshed (at most once a minute per match) when a cup or its
  match list is opened. If the API is unreachable (5 seconds timeout) the page still loads
  and the data is kept as it is. A cup with result_id 0 is managed by hand.

* Setup

  Ruby 3.4.4, Rails 8.0.2, PostgreSQL.

  Environment variables:
    PG_HOST, FOOTBALL_DATABASE, FOOTBALL_USERNAME, FOOTBALL_PASSWORD  : database
    FOOTBALL_API_KEY   : football-data.org token
    SECRET_KEY_BASE    : production only
    SKIP_VALIDATION    : "true" to allow predictions after kickoff
    REPO_URL, REPO_LOGO: footer link

  Run locally:
    bundle install
    bin/rails db:prepare
    bin/dev            (or bin/start.sh to use foreman)

  Run with Docker (reads the variables above from .env):
    docker compose up --build   (web on port 8088)

* Tests

  bin/rails db:test:prepare
  bin/rails test

  The tests never call football-data.org, HTTP is stubbed.
